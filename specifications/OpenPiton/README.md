# OpenPiton — Specifications (vendored)

Full, unabridged official manuals for the OpenPiton manycore research platform, sourced from
`parallel.princeton.edu` (linked directly from the
[PrincetonUniversity/openpiton](https://github.com/PrincetonUniversity/openpiton) README). See
`golden_rtl/OpenPiton/README_VERIFEVAL.md` for RTL provenance and elaboration/lint verification.

| File | Description |
|------|--------------|
| `OpenPiton_Microarchitecture_Specification.pdf` | Full microarchitecture specification of the OpenPiton tile, NoC, and chipset |
| `OpenPiton_Simulation_Manual.pdf` | How to build and run RTL simulations, regressions, and diagnostics |
| `OpenPiton_FPGA_Prototype_Manual.pdf` | FPGA prototyping flow (Genesys2, VCU118, etc.) |
| `OpenPiton_Synthesis_and_Backend_Manual.pdf` | ASIC synthesis and back-end (place & route) flow |
| `images/` | Project logos/block diagrams referenced by the upstream repo's own `README.md` |
