# Open-source specifications

Open-source IP specifications and public-domain standards, with duplicate copies collapsed to one file.
Each PDF keeps the license notice that shipped with it.

- Wishbone B.3 (`protocols/wishbone/wishbone_soc_b3.pdf`) is in the public domain.
- The RISC-V unprivileged ISA manual is at `isa/riscv/riscv-unprivileged-isa.pdf`, with its Creative Commons notice inside the PDF.
- The VeeR EL2 programmer's manual is already in this repo at `golden_rtl/veer_el2/docs/RISC-V_VeeR_EL2_PRM.pdf` (Apache-2.0).
